# 🌤️ Dynamic Weather Dashboard

A responsive JavaScript web application that provides real-time weather forecasts, air quality index (AQI) readings, and a 5-day weather forecast using the OpenWeatherMap API.

---

## ✨ Features

* **City Search:** Look up current weather metrics for any city worldwide.
* **Geolocation Support:** Instantly fetch local weather using device GPS coordinates.
* **Air Quality Index (AQI):** Visual air quality indicator (Good to Very Poor).
* **5-Day Forecast:** Daily midday weather predictions rendered dynamically.
* **Dark / Light Mode:** Persistent theme toggle stored in `localStorage`.
* **Error Handling:** Clean UI feedback for invalid searches or network issues.

---

## 🛠️ Tech Stack

* **HTML5** – Page structure and semantic layout
* **CSS3** – Dynamic styling and theme variables
* **JavaScript (ES6+)** – Asynchronous API handling (`fetch` / `async-await`) & DOM manipulation
* **API:** [OpenWeatherMap API](https://openweathermap.org/api)
